# 普通平键连接强度校核与 2D 工程示意

面向《机械设计基础》课程的纯前端参数化解析校核工具。输入轴、轮毂、键、载荷和材料参数，实时完成普通平键静连接的挤压/剪切强度校核，并通过 Konva 横截面与纵剖面展示结构、尺寸和受力示意。

本系统采用平均应力解析公式，不是有限元仿真软件，不输出应力云图或精确接触应力分布。

## 在线访问

[https://moss-550-w.github.io/simulation/](https://moss-550-w.github.io/simulation/)

## 功能特性

- 支持普通平键 A 型（圆头）、B 型（方头）和 C 型（单圆头）。
- 计算工作长度、接触高度、挤压应力、剪切应力、利用率和安全系数。
- 轴、轮毂和可选键材料的许用挤压应力自动取最小值，并标明来源。
- 提供合格、裕度偏低、失效、无载荷和参数无效五类状态，颜色、图标和文字同步表达。
- Konva 持久 Stage 双视图，支持尺寸线、接触面、剪切面、转矩与力箭头、缩放、平移和高分屏显示。
- 非法输入显示字段错误和画布遮罩，同时保留上次有效结果；`T = 0` 返回无载荷状态，安全系数为 `null`。
- 显示公式数值代入过程、教材例题、标准答案对比、参数敏感性提示及趋势图。
- 支持画布 PNG 导出、参数 JSON 保存/恢复和最近有效参数本地缓存。
- 支持双键 180° 教学简化扩展，载荷分配系数可配置。
- 支持生成包含参数、结果、公式和画布截图的可打印报告，可打印或另存为 PDF。
- 桌面与窄屏响应式布局，提供基础键盘标签和 ARIA 支持。

## 本地运行

建议使用 Node.js 20.19+。

```bash
npm install

```

开发服务器启动后，根据终端提示打开本地地址，默认通常为 `http://localhost:5173`。

## 使用说明

1. 选择键型及单键/双键布置。
2. 输入轴径、轮毂尺寸、键尺寸、槽深和传递转矩，也可按教学简化表应用推荐键尺寸。
3. 输入轴、轮毂及可选键材料的许用挤压应力；需要剪切校核时填写键许用剪切应力。
4. 查看双视图、强度结果和公式代入过程。
5. 可载入教材例题、查看趋势图，或导出 PNG、JSON 和可打印报告。

界面转矩单位为 `N·m`，进入领域计算前统一转换为 `N·mm`；长度单位为 `mm`，应力单位为 `MPa`。

### 工作长度

```text
A 型：l = L - b
B 型：l = L
C 型：l = L - b/2
```

### 单键强度校核

```text
hk = h/2
σp = 2T/(d·hk·l)
τ  = 2T/(d·b·l)
ηp = σp/[σp]
ητ = τ/[τ]
```

综合利用率取已启用校核项目的最大值。`ηmax ≤ 0.8` 为合格，`0.8 < ηmax ≤ 1.0` 为裕度偏低，`ηmax > 1.0` 为失效。

### 双键 180° 扩展

双键采用独立扩展模块，复用单键核心公式：

```text
Ti = T/φ
1 ≤ φ ≤ 2，默认 φ = 1.5
```

默认假设双键合计承载能力为单键的 1.5 倍；`φ = 2` 表示理想均载。结果表示每个键的平均应力，属于教学简化模型，不代表精确载荷分布。

## 数据与隐私

- 最近有效参数仅保存在当前浏览器的 `localStorage` 中。
- JSON 导入会检查版本、字段类型、键布置和几何/材料约束，非法文件不会覆盖当前有效参数。
- 报告和 PNG 均在浏览器本地生成，不上传参数或图像。

## 目录结构

```text
src/
├── domain/                 # 类型、校验、单位换算、单键与双键计算、报告生成
├── composables/            # 输入—校验—计算—结果—视图状态聚合
├── components/             # 参数、材料、结果、公式、画布和教学面板
├── visualization/          # Konva 几何模型与各绘图图层
├── tests/                  # Vitest 领域单元测试
├── App.vue                 # 应用集成与导出入口
└── style.css               # 工程风样式与响应式布局
```

领域公式仅位于 `domain/`。组件和画布只消费计算结果，不重复实现强度公式；画布按图层更新，不销毁并重建整个 Stage。
